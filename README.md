# DormHub — інтерфейс (поки без бази даних)

Десктопний застосунок на Python (CustomTkinter) для гуртожитку: чати, оголошення, події, заявки на ремонт.
Усі дані захардкоджені у `data/mock_data.py`.

## Запуск на Windows

1. Встановіть Python 3.10+ з python.org (під час встановлення поставте галочку **Add python.exe to PATH**).
2. Розпакуйте папку й двічі клацніть **`run.bat`**. Перший запуск сам створить середовище й встановить бібліотеку.

Або вручну в терміналі:
```
pip install -r requirements.txt
python main.py
```

Тестові акаунти: `camper / 1234` (студент), `admin / admin` (комендант, може публікувати оголошення).

## Структура

```
main.py                 точка входу
data/
  mock_data.py          захардкоджені «таблиці» (списки словників)
  repository.py         функції доступу до даних — ЄДИНЕ, що бачить інтерфейс
ui/
  app.py                головне вікно, бічне меню, перемикання сторінок
  theme.py              спільні кольори/шрифти
  module_a/             Люди і проживання: login.py, profile.py, room.py
  module_b/             Чати: chats.py (список, переписка, нова група)
  module_c/             Життя гуртожитку: announcements.py, events.py, requests_page.py
```

Кожен з команди працює у своїй папці `module_*` і у своєму розділі `repository.py`,
тому конфліктів у Git майже не буде.
